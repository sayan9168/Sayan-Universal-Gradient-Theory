# Changelog

All notable changes to this project are documented here. This changelog follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); project versions

## [2.1.0]

### Added

- Citation metadata for the software and accompanying theory materials.
- A source-distribution manifest that includes `paper/`, `figures/`,
  `notebooks/`, `examples/`, and `tests/`.
- Contribution guidance, a code of conduct, a theory FAQ, and GitHub issue and
  pull request templates.
