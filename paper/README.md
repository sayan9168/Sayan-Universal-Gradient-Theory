# SUG Theory -- Written Materials

This folder holds the written documentation of the **Sayan Universal
Gradient (SUG)** framework.  Suggested reading order:

1. **`postulates.md`** — the axioms the theory starts from.
2. **`formal_framework.md`** — definitions, the central operator, and derived
   relations with full working.
3. **`predictions.md`** — falsifiable consequences and a testing roadmap.
4. **`numerical_experiments.md`** — how the code supports the theory, with
   figures.
5. **`open_questions.md`** — honest limitations and the validation agenda.
6. **`glossary.md`** & **`faq.md`** — reference material.
7. **`references.md`** — classical physics SUG builds on.

> **Please read `open_questions.md`.**  SUG is an original *proposal*.  It is
> internally self-consistent by construction, but it has not been validated
> against observation and its free parameters are currently uncalibrated.
> A researcher reading it should treat every prediction as a *to-be-tested
> hypothesis*, not as an established result.
